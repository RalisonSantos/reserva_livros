# reserva_livros
Alunos: Ralison Ruan, Matheus Moura e Henrique Fonseca

Proposta:
O Sistema de Biblioteca Online do IFTO tem como proposta facilitar o acesso dos alunos e servidores aos recursos da biblioteca de forma digital. O sistema permite consultar livros, verificar disponibilidade, realizar reservas e acompanhar empréstimos e devoluções, tornando o processo mais rápido, organizado e acessível.
